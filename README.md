# OpenWebTV - Browser Video Player

> 浏览器端 TVBox 兼容播放器

Browser-based TVBox-compatible video player - import content sources, search and play HLS/MP4 locally

## Features

- Import TVBox-compatible content source configurations
- Search across imported sources
- Play HLS and MP4 streams in the browser
- Local playback controls and history
- No server-side media proxying

## Tech Stack

`Video Player` `HLS` `Browser-based` `TVBox` `Media`
